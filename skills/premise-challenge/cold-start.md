# Cold start: produce an unanchored version, then compare

Use this when you need an independent view: you may already be anchored by the documents you have read, or a full redesign is on the table. You cannot un-read what you have read, so the independent version must come from a context that never saw the existing decisions.

1. Build a clean copy of the repository with the `scripts/make-clean-room.sh` script in this skill's directory (`<this skill's directory>/scripts/make-clean-room.sh <repo> <output-dir-outside-the-repo> <ref>`). It exports the ref and deletes agent instruction files (CLAUDE.md, AGENTS.md, GEMINI.md, Copilot, Cursor, Windsurf and Cline rule files), the `.claude/`, `.codex/`, `.cursor/` and `.windsurf/` folders, `docs`, ADR, RFC and decision directories at any depth, and `doc` and `design` directories at the repository root, then checks that none of the listed names are left. Every symbolic link left in the copy must resolve to an existing path inside it. If a link points outside the copy, to nothing or into a loop, or an extra path goes through a link, the script fails and removes the copy. Pass extra relative paths to delete if your repository keeps decision context elsewhere, and look over the tree yourself.
2. Write a brief for an exploratory task, in a file outside the repository. Include only the goal, the success criteria, external constraints and verified facts, and name the output path. Leave out existing decisions, spec wording and the current design. Do not use words such as "challenge" or "alternative": an agent told to disagree performs disagreement.
3. Give the brief and the clean copy to the `cold-designer` subagent. The Claude Code plugin includes it as `premise-challenge:cold-designer`; a manual install must copy it to `~/.claude/agents/` (see the README). It is set to skip CLAUDE.md files, which needs Claude Code 2.1.271 or later. If the subagent is not available, as in Codex, or the Claude Code version is older or cannot be confirmed, do not run this step: tell the user the cold-start step was not done and why. Do not use a general-purpose subagent instead; it usually inherits your instruction files.
4. Compare: list where the cold version and the existing design disagree. For each disagreement, write the related decision, its original reason, and whether that reason still holds, with evidence. Hand anything you would change to the owner, using the solution and premise-table formats in SKILL.md (Output, items 2 and 3).
