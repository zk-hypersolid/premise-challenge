# Cold start: produce an unanchored version, then compare

Use this when you need an independent view: you may already be anchored by the documents you have read, or a full redesign is on the table. You cannot un-read what you have read, so the independent version must come from a context that never saw the existing decisions.

1. Build a clean copy of the repository with the `scripts/make-clean-room.sh` script in this skill's directory (for example `~/.claude/skills/premise-challenge/scripts/make-clean-room.sh <repo> <output-dir-outside-the-repo> <ref>`). It exports the ref and deletes agent instruction files (CLAUDE.md, AGENTS.md, GEMINI.md, Copilot, Cursor, Windsurf and Cline rule files), the `.claude/`, `.codex/`, `.cursor/` and `.windsurf/` folders, `docs`, ADR, RFC and decision directories at any depth, and `doc` and `design` directories at the repository root, then checks that none of the listed names are left. Pass extra relative paths to delete if your repository keeps decision context elsewhere, and look over the tree yourself.
2. Write a brief for an exploratory task, in a file outside the repository. Include only the goal, the success criteria, external constraints and verified facts, and name the output path. Leave out existing decisions, spec wording and the current design. Do not use words such as "challenge" or "alternative": an agent told to disagree performs disagreement.
3. Give the brief and the clean copy to the `cold-designer` subagent from this skill's `agents/` folder. It must be installed in `~/.claude/agents/` (see the README). It is set to skip CLAUDE.md files. If it is not installed, tell the user instead of using a general-purpose subagent, which usually inherits your instruction files.
4. Compare: list where the cold version and the existing design disagree. For each disagreement, write the related decision, its original reason, and whether that reason still holds, with evidence. Hand anything you would change to the owner, using the recommended-solution and false-premise formats in SKILL.md (Output, items 2 and 4).
